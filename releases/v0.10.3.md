# NFC 写卡台 v0.10.3

- 公开安装包更新源，无需 GitHub 账号或访问令牌。
- 更新清单、更新包均使用 Ed25519 签名校验。
- 修复设置弹层及其关闭动画影响更新启动、安装和自动重启的问题。
- 更新期间禁止启动卡片操作或打开新的编辑弹层，不自动丢弃未保存的编辑。
- 包含 NFC 计数、URL 计数镜像、参数自动补齐及密码配置保留优化。

系统要求：macOS 13+，Apple Silicon（arm64）。

旧版用户请手动安装本版一次，之后可使用应用内更新。更新保留任务数据、历史记录及已存卡片密码。

当前版本未进行 Apple Developer ID 公证；NFC 计数、镜像与密码组合仍需在具体卡片与读写器上验收。
