# NFC 写卡台 v0.10.1

此版本在完整更新验证中发现重启被弹层阻止的问题，已撤回发行；请使用 v0.10.2 或更新版本。

- 新增免登录的公开更新源：无需 GitHub 账号或令牌。
- 更新时验证版本清单和安装包签名，支持下载、安装、重新启动。
- 更新期间阻止启动写卡、卡片检查和读取，避免中断设备操作。
- 支持可选开启 NFC 计数和 URL 计数镜像。
- 镜像网址缺少 `e=000000` 时提示，并支持单条或批量自动补齐。
- 按 NTAG213/215/216 实际卡型选择配置页，设置只防改写密码时保留计数与镜像配置。

系统要求：macOS 13+，Apple Silicon（arm64）。

旧版用户请手动安装本版一次，后续可使用应用内更新。安装包不会包含或替换用户任务数据、历史记录及已存卡片密码。

当前版本未进行 Apple Developer ID 公证。NFC 计数、镜像和密码组合仍需在具体卡片与读写器上验收。
