# NFC 写卡台 v0.10.2

此版本在弹层关闭时序验证中发现问题，已撤回发行；请使用 v0.10.3 或更新版本。

- 无需 GitHub 账号或令牌，直接检查和下载安装更新。
- 修复更新设置弹层阻止自动退出、安装和重新启动的问题。
- 更新过程中禁止打开新的操作弹层，不自动丢弃未保存的编辑。
- 更新清单及安装包均经过 Ed25519 签名校验。
- 包含 NFC 计数、URL 镜像、参数自动补齐和密码配置兼容优化。

系统要求：macOS 13+，Apple Silicon（arm64）。

旧版用户请手动安装本版一次，之后可使用应用内更新。更新保留任务、历史记录及已存卡片密码。

当前版本未进行 Apple Developer ID 公证；NFC 计数、镜像与密码组合仍需在具体卡片与读写器上验收。
