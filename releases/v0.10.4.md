# NFC 写卡台 v0.10.4

## 修复

- 修复正式安装版点击“导出 Excel 模板”后应用立即退出的问题。
- 模板资源改为从 macOS 应用的 `Contents/Resources` 安全解析；资源缺失时显示错误提示，不再触发进程级 Fatal error。

## 密码格式默认值

- 新建任务、任务安全设置、添加/编辑子任务和变量批量生成默认选择“普通密码（NFC Tools）”。
- 新版 Excel 模板的示例、填写说明和下拉选项默认使用普通密码；格式单元格留空也按普通密码导入。
- 旧模板完全没有密码格式列时仍按十六进制导入，避免改变历史文件含义；用户仍可主动切换十六进制模式。

## 验证

- 私有源码仓库 macOS CI 测试、构建和打包通过。
- 在正式 DMG 安装结构中实际点击导出，保存窗口正常显示，导出完成提示正常。
- 导出的 `.xlsx` 可正常解压，且内容与内置标准模板完全一致。
- 模板密码格式下拉已清除旧列遗留的冲突规则，并验证当前五项下拉规则覆盖 2–1000 行。
- 更新前后任务数据校验值一致；本次未执行实卡写入。
