# NFC 写卡台 v0.11.0

## 任务与 Excel

- 修复首页“导入表格创建任务”按钮不可用的问题，改用稳定的 macOS 原生文件选择窗口。
- Excel 模板新增“计数功能”和“镜像功能”两列，可为每张卡单独配置；镜像 URL 缺少唯一 `e=000000` 参数时会指出具体 Excel 行。
- 子任务编辑器和队列表格同步显示逐卡计数、镜像配置。
- 新增“复制子任务”，副本继承内容、动作、计数/镜像和独立密码，但不会复制 UID、写卡结果和执行状态。

## 失败步骤重试

- 写卡失败后可以只重试失败步骤；此前成功步骤保持成功状态，不再从头重复写入。
- 支持任务级批量重试和单条子任务重试，点击后直接重新启动队列。
- 回读校验、密码验证、计数镜像和计数器开启均可从对应失败点恢复。

## 取消卡片密码钥匙串授权

- 卡片当前密码、新密码和 NFC Tools 普通密码原文改用本机 AES-256-GCM 加密密码库，不再调用 macOS 钥匙串，因此不会出现登录钥匙串授权弹窗。
- 加密密文与随机密钥分别保存，应用数据目录权限为 `0700`、文件权限为 `0600`；任务 JSON、历史和线上同步数据仍不保存密码值。
- 旧钥匙串条目不会自动读取或删除。升级后旧任务会显示密码缺失，需要重新编辑任务或子任务录入一次密码。

## 验证

- 私有源码仓库 macOS CI 完成 77 项测试、构建和打包，零失败。
- ZIP 与 DMG 均验证为 v0.11.0（build 21），应用嵌套签名和 DMG 完整性通过。
- 应用可执行文件确认不包含 `SecItemCopyMatching`、`SecItemAdd`、`SecItemUpdate` 或 `SecItemDelete` 卡片密码钥匙串调用。
- Excel 模板重新打开、渲染和导入测试通过，安装包内模板与源码模板 SHA-256 一致。
- 本次没有使用真实 NFC 卡片执行失败步骤恢复，正式批量生产前建议用 ACR122U-A9 和 ACR1552U 各复核一次。
